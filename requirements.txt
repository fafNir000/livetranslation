#   2) Install CUDA-enabled PyTorch FIRST (otherwise pip pulls the CPU-only build):

#   3) pip install -r requirements.txt
#   4) Verify:  python -c "import torch; print(torch.cuda.is_available())"   -> True
#

# run `pip freeze > requirements.lock.txt` and install from that before the interview.
